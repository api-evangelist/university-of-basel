# University of Basel

> The University of Basel (Universität Basel), founded 1460, is the oldest university in
> Switzerland. It publishes no OpenAPI, AsyncAPI or GraphQL contract and runs no developer portal.
> What it operates, on its own hosts, is scholarly and identity infrastructure: the edoc
> open-access institutional repository (DSpace-CRIS 7.6.2) with a REST API and an OAI-PMH 2.0
> interface, a SWITCHaai/eduGAIN SAML identity provider scoped to unibas.ch, an OpenID Connect
> issuer at the sciCORE computing centre, and an LTI launch endpoint on the ADAM learning platform.

Generated by API Evangelist on 2026-08-30 from the University of Basel apis.yml index and the
artifacts in this repository. Not published by the University of Basel. Every URL below was fetched
and its status recorded on that date.

## What you can call without a key

- The edoc DSpace REST API and the edoc OAI-PMH interface are fully anonymous for reads.
- The sciCORE OpenID Connect discovery document is public; obtaining a token from it is not.
- The swisscovery SRU interface is anonymous, but it is SLSP's service, not Basel's.
- There is no pricing, no plan and no quota on any of it.

## APIs

- [edoc DSpace REST API](https://edoc.unibas.ch/server/api): HAL+JSON REST API of edoc, the
  open-access institutional repository. DSpace 7.6.2 / DSpace-CRIS cris-2023.02.06. No contract is
  published; the root document links the whole surface.
- [edoc OAI-PMH](https://edoc.unibas.ch/server/oai/request): OAI-PMH 2.0 harvesting. Eleven
  metadata prefixes (oai_dc, qdc, dim, mods, mets, marc, rdf, ore, didl, etdms, uketd_dc), plus a
  separate OpenAIRE-CRIS context at
  [/server/oai/openairecris](https://edoc.unibas.ch/server/oai/openairecris?verb=Identify).
- [SWITCHaai / eduGAIN identity provider](https://metadata.aai.switch.ch/metadata.switchaai.xml):
  SAML 2.0, entityID `https://aai-logon.unibas.ch/idp/shibboleth`, scope `unibas.ch`, Sirtfi
  certified, REFEDS R&S and GÉANT CoCo v1 tagged. Thirty-two Basel service providers sit alongside
  it in the same aggregate.
- [sciCORE OpenID Connect](https://iam.scicore.unibas.ch/realms/switch-eduid/.well-known/openid-configuration):
  Keycloak realm brokering SWITCH edu-ID into the university's research-computing services.
- [ADAM LTI launch](https://adam.unibas.ch/lti.php): ILIAS LTI entry point. Launch-only, no public
  tool configuration.
- [swisscovery SRU](https://swisscovery.slsp.ch/view/sru/41SLSP_UBS) — TENANCY, not Basel's API.
  SRU 1.2 over Ex Libris Alma, operated by SLSP; Basel holds the 41SLSP_UBS institution zone.

## Who operates what

This matters more here than at a company. Basel is a buyer as much as a builder:

- INSTITUTION-OPERATED: edoc (both interfaces), the SWITCHaai IdP and its 32 service providers,
  the sciCORE OIDC issuer, the ADAM LTI endpoint.
- TENANT: swisscovery/SLSP on Ex Libris Alma; the e-manuscripta.ch consortium platform.
- NOT BASEL'S AT ALL: the DaSCH Service Platform API (api.dasch.swiss). DaSCH is a legally
  independent association that the university hosts and part-funds; its contract names DaSCH as
  contact and api.dasch.swiss as its only server. It was removed from this repository on
  2026-08-30. If you want DSP-API, go to DaSCH.

## Authentication

- edoc reads: none. Writes require a Basel account; there is no self-service developer registration.
- Federated identity for people: SAML 2.0 through SWITCHaai/eduGAIN, and OpenID Connect at
  sciCORE. Neither issues machine credentials to outside developers — a sciCORE OIDC client must be
  created by sciCORE, as no dynamic client registration endpoint is advertised.
- No API keys, no mTLS, no signed requests, anywhere under unibas.ch.

## Persistent identifiers

- Handle prefix 20.500.14716 — edoc identifiers take the form `oai:edoc.unibas.ch:20.500.14716/…`.
- DataCite provider ILEN ("University of Basel", consortium organization, joined 2020-11-02).
- Crossref member 27920, DOI prefixes 10.24437 and 10.12685.
- ORCID is wired into edoc: the metadata registry declares `person.identifier.orcid`,
  `orcid.authenticated`, `orcid.webhook` and the full `cris.orcid.sync-*` family.

## Rate limits

None published, and none signalled. No `RateLimit-*`, no `X-RateLimit-*`, no `Retry-After` on any
live response from any Basel host. Harvest OAI-PMH politely and serially — the courtesy is yours to
supply.

## Known gaps

- No `/.well-known/` document of any kind on any Basel host, and no llms.txt from the university
  itself (www.unibas.ch/llms.txt 404).
- No agent card and no MCP server.
- No public API for the course directory or for the research information system
  (forschdb2.unibas.ch redirects every probed API path back to its Angular shell).
- No open-data portal: data.unibas.ch, opendata.unibas.ch, api.unibas.ch and developer.unibas.ch
  have no DNS record at all.
- No published deprecation policy, SLA, status page or changelog for any Basel-operated surface.
